This sprint is:

PW-C01 — LOCAL AVALANCHE L1 DEVELOPMENT ENVIRONMENT

OBJECTIVE:

Build a completely reproducible LOCAL PrimeWave Chain development environment based on the architecture and dependency decisions established during PW-C00.

The result must allow the development team to:

1. Build the required Avalanche software stack.
2. Create a local PrimeWave L1.
3. Start local validator/node infrastructure.
4. Connect to the chain through RPC.
5. Execute EVM transactions.
6. Verify the chain's native PW asset.
7. Verify block production and basic network operation.
8. Reproduce the environment from a clean checkout.

This is a LOCAL DEVELOPMENT ENVIRONMENT ONLY.

8. NATIVE PW ASSET
============================================================

PrimeWave's native asset:

PW

100,000,000 PW

The objective is only to verify that:

- PW is the gas asset
- EVM accounts can hold PW
