PHASE 4B-2A — NETCUP INDEXER HOST ARCHITECTURE AUDIT

Phase 4B-2 is BLOCKED because no explicitly approved dedicated PostgreSQL server exists.

We have decided on the following architecture:

- PrimeWave testnet validators remain on the existing dedicated Netcup validator servers.
- The PrimeWave testnet indexer should run on dedicated Netcup infrastructure, NOT permanently inside Replit.
- PostgreSQL should be dedicated to the PrimeWave testnet indexer.
- Replit remains development/build infrastructure and must not become a production runtime dependency.
- PWCScan should remain separately deployable and must not be coupled to the validator nodes.
