## Post-Deploy Funding

After contract deployment via `scripts/testnet/deploy-contracts.sh`:

```bash
# DeployTestnet.s.sol calls:
rewardVault.fund{value: 15_000_000 ether}();
require(rewardVault.totalFunded() == 15_000_000 ether, "UNDERFUNDED");
```

The 15M PW flows: Deployer genesis balance → RewardVault.fund() → locked in vault.
